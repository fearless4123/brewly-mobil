# Brewly — شرایط استفاده

Brewly یک پروژه آموزشی برای درس برنامه‌نویسی موبایل دانشگاه ایستینیه است. سفارش‌ها و قیمت‌ها آزمایشی هستند و پرداخت یا تحویل واقعی ارائه نمی‌شود.

## مسئولیت‌های کاربر

برنامه باید برای اهداف آموزشی و مطابق قوانین جاری استفاده شود. اطلاعات پرداخت واقعی یا داده حساس وارد نکنید.

## مالکیت فکری

کد Brewly و دارایی‌های برند آن بخشی از این کار آموزشی است.
